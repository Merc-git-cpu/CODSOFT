# Number Guessing Game

## Description
This is a simple C++ console application that generates a random number between 1 and 100. The user keeps guessing until the correct number is found.

## Features
- Generates a random number
- Provides hints (Too High / Too Low)
- Counts the number of attempts
- Console-based user interface

## Language Used
- C++

## How to Run
1. Compile the program:
   ```
   g++ main.cpp -o game
   ```
2. Run the executable:
   ```
   ./game
   ```
