# To-Do List

## Description
This is a simple C++ console application that allows users to manage their daily tasks. Users can add, view, mark as completed, and delete tasks using a menu-driven interface.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Console-based user interface

## Language Used
- C++

## How to Run
1. Compile the program:
   ```bash
   g++ main.cpp -o todo
   ```
2. Run the executable:
   ```bash
   ./todo
   ```
